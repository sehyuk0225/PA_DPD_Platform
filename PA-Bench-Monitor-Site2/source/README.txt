■ v2.3.21 변경점 - 종류 바꿀 때 전류 읽기 자동 재시작

■ v2.3.20 변경점 - 전류 읽는 구간 (Gate) 도 샘플 종류마다
  - 전류 설정의 "구간 지정 (Gate)" 체크 · 시작 · 끝 · 단위를 샘플 종류 × Pulse / Mod. 로 기억

■ v2.3.18 변경점 - Pulse ↔ Mod. 전환 때 PA Analyzer 중복 그래프 수정
  - 수정: Pulse 기록을 지우지 않고 Mod. 로 갔다가 돌아오면 같은 Pulse 데이터가 PA Analyzer 에 한 번 더 그려지던 문제
     (그래프 창에 지금 모드 기록만 보내서, 모드를 바꾸면 다른 모드 데이터 연결이 끊겼다가 돌아올 때 새 Dataset 으로 생김)
     → Pulse · Mod. 기록을 항상 같이 보내고, 모드를 바꿔도 연결을 유지 (바뀐 것만 다시 보냄)

■ v2.3.17 변경점 - 같은 샘플 안에서도 Pulse · Mod. 따로 기억
  - ② 측정 조건 (끝나면 복귀 · RF OFF · 바이어스 자동 OFF 등) 과 전류 트리거 설정을 샘플 종류 × Pulse / Mod. 로 따로 기억
     Pulse ↔ Mod. 를 바꾸면 그 모드 값으로 바뀜 · 처음엔 예전 (모드 구분 없던) 값으로 시작
  - 샘플 종류 설정 창에서 저장해도 여러 주파수 [사용] · 대기 · 자동 진행 기억은 그대로 남게 수정

■ v2.3.16 변경점 - 샘플 종류마다 기억하는 옵션 추가

  - 여러 주파수 자동 측정: [사용] 체크 · 주파수 사이 대기 · 자동 진행도 샘플 종류마다 (Pulse · Mod. 따로)
  - 처음 고르는 종류는 지금 값으로 시작

■ v2.3.15 변경점 - 저전력에서 트리거 · 스케일 되돌림
  - SG 파워가 [-37] dBm 아래로 내려오면 (전류 설정 "트리거 자동 추적" 아래 줄에서 바꿈 · 샘플 종류마다 기억)
     기억한 상태가 있으면: 저전력에서 잘 잡혔던 트리거 레벨 · 세로 스케일로 되돌림
     없으면 (처음 · 전류 측정 다시 시작): 스케일 = 대기 전류(Idq × 1.3) 가 크게 보이게, 레벨 = Idq × 1.1
  - 저전력에서 트리거가 잘 잡힐 때마다 그 상태를 기억 (1초마다)
  - 저전력에서 RF ON (Mod. 다음 주파수 등) 일 때도 높은 파워 때 스케일이 아니라 위 상태로
     → 첫 주파수 측정 뒤 파워를 내릴 때 트리거 · 스케일이 높은 곳에 남아 다음 주파수 낮은 파워에서 못 잡던 문제

■ v2.3.14 변경점 - RF OFF 스케일 항상 · Mod. 안내 창 없앰
  - SG RF OFF → 세로 스케일 자동이 꺼져 있어도 항상 대기 전류가 크게 보이는 mA 스케일로, RF ON 하면 원래 스케일로
  - Mod. 측정 중 작은 안내 창 없앰 (옵션도 없앰) · 긴급 정지는 Esc / 위쪽 [긴급 정지] 버튼, 목표 Pout 자동 멈춤은 그대로

■ v2.3.13 변경점 - 전류 트리거: 평균과 꼭대기 사이 · 잡은 뒤 안 내려감
  - 레벨 = 평균 + (펄스 꼭대기 - 평균) × 30%  (최근 새 파형 3개 기준 · 꼭대기 = 구간 안 윗부분의 90% 지점, 스파이크 무시)
     꼭대기를 모르는 "스코프 측정 읽기" 모드는 평균 × 비율
  - 잡은 뒤에는 위로만 움직임. 내려가는 건 SG 파워를 내린 뒤 4초 동안만 (트리거를 놓쳐 찾을 때는 예전처럼 아래쪽부터)
  - SG RF OFF 동안은 트리거를 찾지 않음 (펄스가 없음) → RF ON 하면 다시 추적

■ v2.3.12 변경점 - SG RF OFF 때 전류 화면 mA 스케일
  - SG RF OFF → 전류(RTO) 세로 스케일을 대기 전류(파워서플라이 Vdd 전류 × 1.3)가 화면 75% 안에 크게 보이는 가장 작은 값으로
     RF OFF 동안은 자동 스케일이 화면에 남은 예전 펄스 때문에 다시 커지지 않게 멈춤
  - SG RF ON → RF 켜져 있던 때 스케일로 바로 되돌림 (작은 스케일에서 한 칸씩 키우지 않음)
  - 전류 측정 중 + "세로 스케일 자동" 이 켜져 있을 때만 동작

■ v2.3.11 변경점 - 전류 트리거: 레벨 = 측정값 평균
  - 레벨 = 최근 새 파형 3개의 측정값 평균 × 비율, 비율 기본 90% → 100% (예전 90 으로 저장된 값도 100 으로 한 번 바꿈)
  - SG 파워 올림: 레벨을 미리 올리지 않음 (펄스가 커지므로 지금 레벨에서도 계속 걸림) → 새 파형 평균이 나오면 그 값으로
     (미리 올렸다가 놓치고 한 칸 아래로 내려갔다 다시 올라오던 것 없앰)
  - SG 파워 내림: 예상 전류로 미리 내림 · 놓치면 아래쪽부터 찾음 (레벨이 펄스보다 높은 경우가 대부분)
  - 4% 넘게 달라질 때만 레벨을 옮김 · 그 밖은 v2.3.10 (= v2.3.3) 과 같음

■ v2.3.10 변경점 - 전류 트리거 알고리즘 되돌림

■ v2.3.9 변경점 - 전류 트리거 (피킹이 켜지는 구간)

     → 방향이 바뀌거나 예상값이 15% 넘게 달라지면 하던 탐색을 버리고 새 예상 위치에서 다시 찾음

■ v2.1.3 변경점 - POWER SUPPLY ON: 지금 장비 상태에서 이어서 진행 (0 ~ 4) · 여러 주파수 엑셀 자동 저장

     1. 게이트 기본값 적용 → 전체 ON → 읽은 전압이 설정값과 다르면 (오차 > 0.05 V) 게이트 바로 OFF + 빨간 경고 (Vdd 는 켜지 않음)
     2. Vdd 0 V 로 ON
     3. 0.1 V 쇼트 확인 → 1 V 씩 48 V (단계마다 쇼트 · 게이트 확인) → 48 V 에서 전류 없는지 확인
     4. 초록 게이트를 천천히 내려 목표 전류 (예 100 mA)

  - [OFF] 순서: 초록 게이트 기본값 → 노랑 게이트 기본값 → Vdd 전류 없는지 확인 → Vdd 1 V 씩 0 V
                → 0 V 에서 5 초 대기 → Vdd OFF → 5 초 뒤 게이트 전체 OFF (대기 시간은 설정에서 변경)
  - 이상이면 알림음 대신 바로 빨간 경고 창 + 항상 [게이트 기본값으로 빠르게 → 기본값 확인 → Vdd 1 V 씩 빠르게 0 V]
     1) 게이트를 내리기 전인데 Vdd 전류 ≥ 20 mA (값 변경 가능)
     2) ON 상태에서 측정 중 전류가 직전 값보다 갑자기 치솟음 (≥ 50 % 그리고 ≥ 100 mA) 또는 최대 Id 1.5 A 초과
        → PA Bench Monitor 자동 측정 즉시 중지 + SG RF OFF, 파워서플라이 화면으로 전환
     3) 게이트 이상: 읽은 전압이 설정값과 다름 (> 0.05 V) · 게이트 출력이 꺼짐 · 게이트 전류 > 5 mA
     4) 그 밖에 예상과 다른 동작 (Vdd 가 안 켜짐, 게이트 최소 한계 도달, 조정 중 과전류, 통신 오류 등)

■ 측정 순서 (예)
  1. 각 탭에서 IP 입력 → 상단 [모두 연결]
  2. 상단 [▶ 전류 측정 시작/정지]  (또는 RTO2044 탭에서 ▶ 측정 시작)
  3. 측정 기록 탭에서 주파수 입력 → [SG + SA 주파수 함께 변경], SG 레벨(시작) / 스텝 / 최대 허용 입력
  4. [● 자동 측정] → 시작 레벨부터 최대 허용까지 자동으로 올리며 기록
     (수동으로 하려면 [4] 올리기 · [5] 기록 · [6] 내리기)
  5. 측정 기록 탭 [엑셀용 복사] → 엑셀에서 Ctrl+V  (DRM 엑셀에도 붙여넣기 가능)
  * [지금 기록] : 파워 변경 없이 바로 한 줄 기록 (최근 평균 시간 구간)

■ 장비 앞 패널 잠금 관련
  원격 명령을 받으면 R&S 장비는 REMOTE 상태가 되어 앞 패널이 잠깁니다.
  "읽은 뒤 바로 Local 복귀(&GTL)" (기본 켜짐) → 매번 읽은 직후 Local 로 돌려
  SMW 앞 패널로 파워를 계속 조절할 수 있게 합니다.
  손잡이 조작이 가끔 씹히면 SMW 탭의 [읽기 주기]를 500~1000 ms 로 늘리세요.

■ 안전
  SMW 탭의 레벨 설정/▲ 버튼은 "최대 허용(dBm)" 보다 높게 설정하지 않습니다.
  프로그램이 RF ON/OFF 는 건드리지 않습니다.

■ 기타
  - 설정은 종료 시 자동 저장 (%APPDATA%\PABenchMonitor)

  - 사용 명령: SMW  SOUR1:FREQ? / SOUR1:POW? / OUTP1:STAT? (SOUR1:POW <lvl>)
               FSW  SENS:FREQ:CENT? / SPAN? / CALC1:MARK<n>:STAT? / X? / Y? (MAX)
